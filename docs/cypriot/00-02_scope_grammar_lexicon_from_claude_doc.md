# Cypriot Greek tutor: inventory of existing resources

Oct 10, 2026 · @Stergios Chatzikyriakidis

## Scope and conventions

This inventory covers Cypriot Greek material beyond the five items already in hand (Newton 1972; Andreou, 2nd ed.; Arvaniti's JIPA illustration; GRDD and GRDD+; Ioannidou, Karatsareas, Tsiplakou and Lytra 2020). Each category table uses the requested columns: reference, contents, access, reuse status, judgement, contact.

Reuse codes: **PD** public domain; **Open** licence allows reuse with attribution; **Ask** copyrighted or unclear, needs the holder's permission; **No** reuse excluded by terms. Rules and facts a source describes can inform the tutor's grammar without permission; its example sentences, tables, word lists and recordings cannot.

Verification: items checked on a primary or institutional page carry a link. **\[unverified\]** marks details I could not confirm (page ranges, sizes, current affiliations).

## 1. Grammatical descriptions

There is still no modern reference grammar of the koine beyond Andreou; the tutor's rules have to be assembled from theses and articles. Those marked **Implementable** state conditions explicit enough to code as rules or paradigms.

## 2. Lexical resources

The largest dictionaries are Παπαγγέλου 2001 (about 37,000 entries) and Γιαγκουλλής 2014 (24,054 words), both print and copyrighted. The only lexicon that is both open and machine-readable is the Wiktionary material (about 490 Greek Wiktionary pages plus 64 English ones, CC BY-SA). The Συντυχιές database (over 15,000 lemmas) survives only through its successor site lex-cy.com, which declares its data open for reuse with attribution but offers no bulk download, so a usable lexicon would have to be scraped or requested from Μ. Κατσογιάννου.
