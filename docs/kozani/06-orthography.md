## 6. Orthography

No explicit orthographic standard for the Kozani idiom or for Northern Greek in general was found: scholarly work transcribes in IPA (ΚΕΝΔΙ) or in the ΙΛΝΕ Greek-alphabet system with added symbols, while dialect texts use the Greek alphabet with an apostrophe for every deleted unstressed /i/ and /u/ (κάν', σπίτ', τ' Γιάνν'), phonetic ι and ου for raised /e/ and /o/ (πιδί, χουριό), standard accent marks, and τσ or τζ without diacritics for the affricates, the only verified evidence for this practice being the Northern Greek (Lesbian) treebank on GitHub. In this session the network policy allowed only GitHub hosts and the shared web search budget was exhausted after the first queries, so every row except the two GitHub rows and the two rows derived from that treebank's data is marked [unverified: page not opened] and rests on search results only.
