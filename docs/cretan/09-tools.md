## 9. Existing tools

Everything that handles Cretan as a class or a target is GRDD-derived and sits in the author's own GitHub account: word n-gram classifiers (Cretan F1 0.92) and a BiLSTM (Cretan F1 0.88) from the GRDD paper, a five-class Flask detector, LoRA fine-tuning scripts and adapters for Llama 3, Llama 3.1 and Krikri-8B trained on GRDD+, a perplexity study of eight varieties, and a Cretan to Standard Greek translation collection site, all under CC BY-NC-SA 4.0 or research-only terms, so none is cleared for a commercial app without asking. No Cretan machine translation model, lexicon tool, morphological analyser, spell checker, keyboard, ASR or TTS model, or mantinada generator exists in public code, and the open baselines the tutor can build on are Standard Greek only (GreekBERT MIT, Whisper MIT, eSpeak NG GPL-3.0, Piper, the el_GR Hunspell dictionary, Common Voice Greek, Wiktextract MIT), with the correction that the spaCy Greek models are CC BY-NC-SA 3.0, not MIT. Web search was unavailable to this section, so only GitHub pages were opened and the Hugging Face, Zenodo, clarin:el and ACL Anthology items in the brief could not be checked.
