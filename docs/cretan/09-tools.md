## 9. Existing tools

Cretan-specific tooling exists in three clusters: GRDD-derived classification and fine-tuning in the author's own GitHub account (word n-gram classifiers with Cretan F1 0.92, a BiLSTM with Cretan F1 0.88, a five-class Flask detector, LoRA scripts and adapters for Llama 3, Llama 3.1 and Krikri-8B, a perplexity study, a Cretan to Standard Greek translation collection site, all CC BY-NC-SA 4.0 or research-only), ILSP's Cretan speech work (a CC BY 4.0 eastern Cretan radio corpus, the xls-r-greek-cretan model at 28.27% WER, a VarDial 2026 benchmark extension), and two openly licensed syntactic resources that already contain Cretan (UD_Greek-Cretan, 270 sentences, CC BY-SA 4.0, and the open-greek dilemma lemmatizer and parser, MIT, 273 Cretan headwords, parser trained on the Cretan treebank). No Cretan machine translation model, TTS voice, spell checker, keyboard, mantinada generator or chatbot was found, the open Standard Greek baselines (GreekBERT MIT, Whisper MIT, eSpeak NG GPL-3.0, Piper, Hunspell el_GR, Common Voice el CC0, Wiktextract MIT) handle no Cretan, and the spaCy Greek models are CC BY-NC-SA 3.0, not MIT. GitHub pages were opened directly, the rest rests on 20 web searches and carries the [unverified: search only] marker.
