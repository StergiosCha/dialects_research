## 1. Grammatical descriptions

No reference grammar of contemporary spoken Cretan written with modern linguistic methods exists. The only full grammar sketch is Πάγκαλος's 1955 διάγραμμα γραμματικής, so the tutor's rules must be assembled from four partial sources: Πάγκαλος (paradigms), Κοντοσόπουλος (east vs west isoglosses), Χαιρετάκης 2020 (inflection classes) and the University of Crete phonetics papers (palatalization, affrication, retroflex /l/, vowel assimilation), with syntax (clitic order, indirect object case) covered only by cross dialectal or historical studies.
