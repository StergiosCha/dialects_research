## 2. Lexical resources

The large Cretan dictionaries (Πάγκαλος in six lexicon volumes, Ξανθινάκης for the west, Πιτυκάκης for the east, Τσιριγωτάκης and Ιδομενέως island-wide with 11,000 to 13,000 entries each) are all print, copyrighted and without any digital edition, so none can be loaded by the tutor without a licence from the publisher or heirs. The only open and machine-readable Cretan lexical data found are small: the Wiktionary Cretan categories (273 tagged headwords per the dilemma project count, CC BY-SA), the UD_Greek-Cretan treebank (1,009 lemmas with manual morphological features, CC BY-SA 4.0) and Κονδυλάκης's 4,000 word public domain list, which exists only on paper.
