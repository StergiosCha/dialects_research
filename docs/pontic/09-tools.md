## 9. Existing tools: NLP software, dialect identification, language models, licences

No Pontic-specific NLP tool exists beyond keyboards and fonts: Pontic has a code (pnt) and a Glottolog taxonomy, one open language identifier (GlotLID) recognises it, the only classifier, generative adapters and perplexity studies that cover it are the author's own GRDD-trained work, the two Universal Dependencies efforts hold no data yet, and no machine translation, speech recognition, spell-checker or Pontic-tagged HuggingFace model could be confirmed. Because the web-search budget of this session was exhausted before this section started, every fact below comes from a GitHub page or raw file that was opened, and items hosted elsewhere are listed as not checkable in the "Not found" line.
